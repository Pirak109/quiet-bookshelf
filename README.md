# 余白の本棚

OneDriveのTXTを横書きで読む、個人用の小さな本棚です。

公開先: https://pirak109.github.io/quiet-bookshelf/

ChatGPTへのログインやPlus契約は不要です。GitHub Pagesで配信する静的アプリで、Microsoftの個人用アカウントに接続します。

本文の最後の星をタップすると1〜5の評価を保存できます。本棚の「☆3」「☆5」から再評価・解除できます。以前のお気に入りは星5として引き継ぎます。星が多い順・少ない順、TXTの1行目にある作者名順で並べ替えられます。未評価・作者名が空の本はそれぞれ後ろに表示します。

## 最初の接続

Microsoft Entraで既存のアプリ登録を開き、「認証」のシングルページアプリケーション（SPA）に公開先URLを末尾の `/` まで登録してください。個人用Microsoftアカウント、Microsoft Graphの委任された `Files.Read` を使い、クライアントシークレットは不要です。

本棚の設定にそのアプリのクライアントIDを入れ、MicrosoftにログインしてTXTのあるフォルダを選びます。新しいTXTは「更新」で表示します。

## お気に入り・読書位置の引き継ぎ

1. 普段読んでいる端末とブラウザで、移行前の本棚を開きます。
2. 画面下の「引き継ぎ・バックアップ」からJSONを保存します。
3. この本棚で同じ画面を開き、保存したJSONを選び、表示件数を確認して取り込みます。
4. 同じMicrosoftアカウントに接続します。

星評価は合流し、同じ本の評価は現在の端末にあるものを優先します。読書位置は保存日時の新しいものを優先します。読書設定とフォルダ設定も含みます。本文、ログイン用トークン、キャプションのキャッシュはバックアップに含みません。以前の形式のバックアップも取り込めます。

本文はMicrosoftからブラウザへ直接取得します。お気に入りと読書位置はブラウザ内に保存し、GitHubへ送信しません。ブラウザのデータを削除する前にはバックアップしてください。複数の端末間の自動同期はありません。

## 更新するとき

GitHub Pagesは `main` ブランチのルートを公開します。HTML、CSS、JavaScriptのみでビルドは不要です。公開URLを維持するため、GitHubのユーザー名・リポジトリ名・Pagesのドメイン設定は変更しないでください。通常のファイル更新でURLを変える必要はありません。

このリポジトリにTXT本文やバックアップJSON、秘密鍵を追加しないでください。Microsoft認証ライブラリは同梱したMSAL Browser 3.28.1（MIT、THIRD-PARTY-NOTICES.mdを参照）を使用しています。
