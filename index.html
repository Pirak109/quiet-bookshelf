OneDriveの接続

最初の1回だけ、Microsoft側でこのアプリを登録します。

初回設定の手順
  1. Microsoft Entraの「アプリの登録」を開き、「新規登録」を選びます。
  2. 名前は「余白の本棚」。対応するアカウントは「個人用Microsoftアカウントのみ」、または個人用を含む種類を選びます。
  3. リダイレクトURIの種類をシングルページアプリケーション（SPA）にして、下のURLを登録します。
  4. 登録後の「アプリケーション（クライアント）ID」を下に入力します。
  5. 「APIのアクセス許可」から Microsoft Graph → 委任されたアクセス許可 → Files.Read を追加します。

クライアントシークレットは不要です。登録画面に入れず、ディレクトリ作成を求められる場合は、先にMicrosoft Entraのテナントが必要です。

Microsoftの公式登録ガイド

許可するのはファイルの読み取りです。本文はブラウザで読み込み、OneDriveのファイルは変更しません。

保存されているAndroidのChromeなど、普段読んでいる端末・ブラウザでバックアップを作ってください。

この端末から保存

お気に入り・読書位置・表示設定・接続先フォルダを保存します。本文やログイン用トークンは含みません。

バックアップから引き継ぐ

お気に入りは合流し、読書位置は新しい記録を優先します。取り込み後はMicrosoftにログインし直してください。
